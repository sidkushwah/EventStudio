# 🎟️ OmniEvent Studio

> **Universal Modular Event Management Engine** — A modern, role-based platform built to plan, coordinate, and execute any type of event (Tech Fests, Concerts, Weddings, and Corporate Summits) with a sleek dark glassmorphic UI.

---

## ✨ Core Features

*   **🔒 Secure Auth & Multi-Role Portal**: Complete login/registration system with role-based routing for **Attendees**, **Volunteers / QR Teams**, and **Higher Authority (Organizers)**.
*   **📱 Attendant UID & QR Passes**: Instant generation of unique Customer UIDs and scannable passes complete with required event instructions.
*   **🛡️ Anti-Fraud Gate Scanner**: Built-in verification desk that tracks check-ins and blocks duplicate scans at venue checkpoints in real time.
*   **👥 Volunteer & Pay Coordination**: Streamlined request workflow for staff roles (Guards, Pass Scanners, Parking, Chefs) with expected pay tracking and approval states.
*   **👑 Event Dashboard & Editing**: Full-control manager panel to update event details, adjust capacities, and view expandable volunteer/attendant records.
*   **🎨 Responsive Glassmorphic UI**: Optimized layout featuring dynamic 3-option hubs (side-by-side on desktop, stacked on mobile).

---

## 🛠️ Tech Stack

*   **Backend**: Python, Flask, SQLite (`sqlite3`)
*   **Frontend**: HTML5, CSS3 (Glassmorphism & CSS Variables), JavaScript (Vanilla ES6)
*   **Security**: SHA-256 Hashing, HMAC-style unique token generation
